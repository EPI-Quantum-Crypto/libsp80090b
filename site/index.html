Measure the entropy of a noise source before you trust it.

libsp80090b runs the four NIST SP 800-90B assessments on a buffer in memory, on the machine where the source lives. It returns the same values as the NIST reference tool, and it comes with labs and notes that show what the tests catch and what they miss.

Raw thermal noise, 8-bit ADC, one sample per byteThe source sticks: the RCT stops it after 6 identical samples (H = 4.09 bits)

What it does

A deterministic generator only stretches the entropy of its seed, so the security of a whole random bit generator rests on one number: the min-entropy per sample of the raw noise. SP 800-90B estimates it with an IID track, ten non-IID estimators, a restart test and a conditioning formula.

The library ports the NIST tool to C99 as four functions. From the measured entropy you size the DRBG seed, the thresholds of the RCT and APT health tests, and the input of a conditioning function.

Same results as NISTLargest gap of 7.2 × 10−14 on the 11 NIST reference datasets, checked by make check in CI.

Known ground truth18 simulated sources whose true entropy is known, from healthy noise to saturation, drift, replay and DRBG output.

Honest about limitsAn AES stream with an all-zero key scores 7.87 bits out of 8. The notes explain why, and what to do about it.

Run the experiments

In your browser, nothing to install

  1. Sign in to GitHub, then open a codespace on this repository.
  2. Wait for the build to finish in the terminal: the environment installs the dependencies and runs make.
  3. Run the commands below in the terminal.

A codespace runs on your own GitHub account and uses its free monthly allowance. Stop it when you are done.

On your own Linux machine

# dependencies (Ubuntu or Debian)
sudo apt-get install -y build-essential libdivsufsort-dev libbz2-dev openssl gawk
git clone https://github.com/EPI-Quantum-Crypto/libsp80090b.git && cd libsp80090b
make                            # library, test programs
make check                      # NIST selftest + API self-test

Reproduce the results of the notes

lab/gen_data.sh all --seed 90   # the datasets, about 10 s
lab/lab2.sh                     # non-IID track, a few minutes
lab/lab3.sh                     # restart test, needs lab 2
lab/lab4.sh                     # conditioning, needs lab 2
lab/lab1.sh                     # IID track, several hours: run it last

Or run everything in order with lab/run_all.sh, adding --with-lab1 for the IID track. Results are written to lab/results/; the published ones are in the repository, so you can compare line by line.
