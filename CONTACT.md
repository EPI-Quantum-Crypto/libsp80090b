# Contacting the maintainers

| Need | Channel | Visibility |
|------|---------|-----------|
| Clarification, deeper technical detail, derivation | [Technical detail request](https://github.com/EPI-Quantum-Crypto/libsp80090b/issues/new?template=technical-question.yml) | Public |
| Error in a note, bug in the code | [Erratum or bug report](https://github.com/EPI-Quantum-Crypto/libsp80090b/issues/new?template=erratum.yml) | Public |
| Security issue | See [`SECURITY.md`](SECURITY.md) | Private |
| Unpublished data, raw lab results, collaboration | **epi-quantum-crypto@proton.me** | Private |

Please state the note or code version, the section, your platform (MCU, FPGA, Linux SoC…)
and your goal (research, teaching, product qualification, ESV preparation).
Answers are best-effort. The maintainers do not certify products and do not act on behalf
of NIST or of an accredited laboratory.
